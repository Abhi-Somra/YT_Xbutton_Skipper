# 🖱️ YouTube Mouse XButton Skipper (Brave / Chrome Extension)

A lightweight browser extension (Manifest V3) that lets you control YouTube and YouTube Shorts playback using your mouse side buttons (**XButton1 / Mouse 4** and **XButton2 / Mouse 5**).

---

## ✨ Features

- ⏩ **Instant Video Seeking**: Skip forward or backward by configurable seconds (default 5s, adjustable from 1s to 60s).
- 🖱️ **Customizable Side Button Actions**:
  - Seek Backward / Forward
  - Previous / Next Video
  - Previous / Next Chapter (auto chapter markers)
  - Play / Pause
  - Volume Up / Down
  - Cycle Playback Speed (1x, 1.25x, 1.5x, 2x, etc.)
- 🚫 **Blocks Default Browser History Navigation**: Prevents accidental page back/forward navigation when clicking side buttons on YouTube.
- 📱 **YouTube Shorts Support**: Works smoothly on standard watch pages and YouTube Shorts.
- 📺 **Sleek HUD / OSD Overlay**: Elegant on-screen feedback badge displaying the action triggered.
- 🧪 **Live Mouse Button Tester**: Test and identify your mouse side buttons directly within the popup settings UI.

---

## 🚀 How to Install in Brave (or Chrome / Edge)

1. Open **Brave** browser.
2. Navigate to: `brave://extensions` (or `chrome://extensions` in Chrome).
3. Toggle on **Developer mode** in the top-right corner.
4. Click the **Load unpacked** button in the top-left corner.
5. Select the `mouse_gestures` folder from this project directory:
   ```
   c:\Users\abhis\antigravity_workstation\mouse_gestures
   ```
6. The extension is now installed and active! 🎉

---

## ⚙️ How to Customize

1. Click the **Extensions puzzle icon** in your browser toolbar and pin **YT XButton Skipper**.
2. Click the extension icon to open the settings popup.
3. Configure your preferences:
   - Choose actions for **Mouse 4 (Back)** and **Mouse 5 (Forward)**.
   - Adjust the **Seek Step Duration** slider (e.g., 5s, 10s, 15s).
   - Toggle **Shorts support** or **On-screen display (OSD)**.
4. Settings are automatically saved and applied in real-time.

## 🎯 Default Controls

| Mouse Button | Default Action | Configurable Actions |
| :--- | :--- | :--- |
| **Mouse 4 (Back side button)** | ⏪ Seek -5s | Previous Video, Previous Chapter, Volume Down, Play/Pause |
| **Mouse 5 (Forward side button)** | ⏩ Seek +5s | Next Video, Next Chapter, Volume Up, Speed Toggle |
